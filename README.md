# brennankingmartin.com

My personal site: who I am, what I've built, and how to reach me. Live at **[brennankingmartin.com](https://brennankingmartin.com)**.

## What's on it

- **Projects:** EarnVouch (live on the App Store), JuniorJobHunt, my field-service analytics app, a multi-agent product pipeline, freelance web design, and a legislative campaign mapping tool
- **Experience, awards and skills**
- **Resume and CV** as PDFs, plus a recommendation letter

## How it's built

One hand-written `index.html` with no framework and no build step, served by GitHub Pages on a custom domain. Fonts come from Google Fonts. Everything else is inline.
